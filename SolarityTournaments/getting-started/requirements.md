## Server

- Minecraft 26.3 or newer
- Paper or Folia (Canvas works too)
- Java 25 or newer

## Optional plugins

None of these are needed to load. A board whose source is missing stays at zero, and the console warns
about it once at startup.

| Plugin | What it adds |
|---|---|
| SolarityGens | Counts generator blocks for the Blocks Mined board |
| SolarityEconomy 1.1.0+ | Counts money for the Money Earned board |
| EssentialsX | Counts money for the Money Earned board when SolarityEconomy isn't installed |
| ExcellentCrates | Runs the default prize commands (`crates key give ...`) |
| PlaceholderAPI | The `%solaritytournaments_...%` placeholders |
