# Solarity Plugin Docs

Documentation for the plugins that run SolarityMC's GenSMP. Each plugin has its own folder; start at its introduction page and follow the links from there.

| Plugin | What it does | Server |
|---|---|---|
| [SolarityGens](SolarityGens/intro.md) | The generators: click-to-mine gens in the warzone and claim gens in each player's claim. Formerly DytchsGens. | Paper / Folia 26.3 |
| [LandClaim](LandClaim/intro.md) | Land claims on WorldGuard regions, with ranks, flags, plots and town tiers. SolarityGens builds its claims on it. | Paper / Folia 26.2 or 26.3 |
| [SolarityCombat](SolarityCombat/intro.md) | Combat tag, no logging out mid-fight, item caps and Kill Tokens. | Paper / Folia 26.3 |
| [SolarityItems](SolarityItems/intro.md) | Custom items with click abilities, one file per item. | Paper / Folia 26.3 |
| [SolarityMilestones](SolarityMilestones/intro.md) | Season milestones for kills, blocks mined, playtime and store support. | Paper / Folia 26.3 |
| [SolarityTournaments](SolarityTournaments/intro.md) | A weekly tournament with three boards and Seasonal Key prizes. | Paper / Folia 26.3 |
| [SolarityLeaderboards](SolarityLeaderboards/intro.md) | Leaderboards in a menu and through PlaceholderAPI. | Paper / Folia 26.3 |

## Each plugin's pages

- **Getting started:** requirements, installation and a quick start.
- **Configuration:** every config file, key by key, and message customization.
- **Core reference:** commands, permissions, menus and placeholders.
- **Features:** one page per feature.
- **Integrations:** Vault, PlaceholderAPI, WorldGuard and the other plugins it works with.
- **Support:** common issues and the FAQ.

## For the new season (Folia 26.3)

These plugins need a 26.3 server. LandClaim, and so SolarityGens' claims, need WorldGuard and
FastAsyncWorldEdit-Folia **26.11.0 or newer** on 26.3; see
[LandClaim's requirements](LandClaim/getting-started/requirements.md).
